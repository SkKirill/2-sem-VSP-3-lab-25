# Задача 25  

Имеется таблица T результатов некоторого шахматного турнира, в котором участвовало n шахматистов (n > 2).  
```Pascal
T : array [1..n, 1..n] of (V, H, P, X)
```
, где `T[i,j]=V`, если i-ый участник выиграл у j-ого (при этом `T[i,j]=P`), если i-ый и j-ый участники сыграли в ничью , то `T[i,j]=H` и `T[i,i]=X`.  

За выигрыш дается 2 очка, за ничью – 1 очко, за проигрыш – 0 очков.  
Выдать на печать номера участников в порядке невозрастания набранных очков.
